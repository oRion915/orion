# GPS Tracker Dashboard

A real-time GPS tracking dashboard built with FastAPI, SQLite, Leaflet.js, and JavaScript.

## Features

- Live GPS location
- Interactive map
- Route history
- SQLite database
- REST API
- Responsive dashboard

## Tech Stack

Backend
- FastAPI
- SQLite
- Python

Frontend
- HTML
- CSS
- JavaScript
- Leaflet.js
